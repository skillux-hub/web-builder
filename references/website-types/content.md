# Content, publishing, and portfolios

Use for: Blogs, news, magazines, knowledge bases, author/creative portfolios.

## Scope and workflow

Categories/tags -> list/search -> public detail; admin draft -> publish -> archive.

## Module selection

content, media, lists, seo; inquiries if contact is requested.

Resolve these module names through the [module index](../modules.md); load only selected modules and their applicable dependencies. Suggested modules describe requirements, not prebuilt features.

## Admin and boundaries

Admin by default for multi-page publishing unless declined; a one-page portfolio follows the single-page admin question.

Accounts, comments, paid access, and newsletters are requirement-driven. Confirm payment need for paid content; protect entitlements server-side.

## Acceptance

Draft stays private -> publish appears publicly -> edit persists -> archive removes public access; real pagination and metadata.

Use [Verification](../verification.md) for execution evidence and completion status.
