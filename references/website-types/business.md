# Business websites and service portfolios

Use for: Company sites, agencies, professional services, multi-page portfolios.

## Scope and workflow

Home, services, cases/projects, about, and contact as needed.

## Module selection

content, media, seo, lists for collection pages; inquiries for actual submissions.

Resolve these module names through the [module index](../modules.md); load only selected modules and their applicable dependencies. Suggested modules describe requirements, not prebuilt features.

## Admin and boundaries

Admin by default unless explicitly declined; ask for admin only when this is actually single-page.

Product/service display does not imply selling. Add bookings for scheduled services, commerce for confirmed orders, and accounts only for a real portal.

## Acceptance

Admin publishes a service/case -> frontend list/detail updates -> customer inquiry -> actual handling.

Use [Verification](../verification.md) for execution evidence and completion status.
