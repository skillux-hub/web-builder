# Education and training

Use for: Schools, course catalogs, cohort enrollment, online learning.

## Scope and workflow

Course discovery -> enrollment -> processing; lesson/material access only for actual learning delivery.

## Module selection

learning, content, lists, seo, media; bookings for dated capacity; authentication for learner accounts when needed.

Resolve these module names through the [module index](../modules.md); load only selected modules and their applicable dependencies. Suggested modules describe requirements, not prebuilt features.

## Admin and boundaries

Admin by default unless explicitly declined; respect the single-page exception.

Distinguish course promotion from enrollment and learning delivery. Confirm paid/free enrollment. Do not substitute product/cart models for course/cohort models.

## Acceptance

Publish course -> enroll -> capacity/admin update -> authorized lesson access if requested; enforce private-material restrictions.

Use [Verification](../verification.md) for execution evidence and completion status.
