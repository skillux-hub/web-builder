# Directories, listings, and classified platforms

Use for: Property, jobs, service directories, listing marketplaces.

## Scope and workflow

Categories/filter/search -> listing detail -> contact/submission/moderation as required.

## Module selection

directory, lists, content, media, seo; inquiries for lead workflows.

Resolve these module names through the [module index](../modules.md); load only selected modules and their applicable dependencies. Suggested modules describe requirements, not prebuilt features.

## Admin and boundaries

Admin by default unless explicitly declined; user publishers and administrators have separate permissions.

Read-only versus user submissions and paid listings are independent choices. Add accounts, bookings, or payments only for their confirmed workflow; do not assume vendor settlement.

## Acceptance

Publish/moderate listing -> filtered public results/detail -> contact; reject other-publisher edits and exclude drafts from search/counts.

Use [Verification](../verification.md) for execution evidence and completion status.
